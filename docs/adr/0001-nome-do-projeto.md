# Nome do projeto: pleito

## Status
Aceita

## Contexto
Q1 do plano pedia um nome de mercado melhor que `aplicador-curriculos`, que descreve a
funcao mas nao serve como nome de produto e fica ruim como repositorio publico.

## Decisao
`pleito`. Palavra portuguesa para candidatura ou disputa, curta, pronunciavel nos dois
idiomas do projeto, sem colisao obvia no ecossistema de ferramentas de vaga.

## Consequencias
- repositorio publico `lipe0312/pleito`, namespace Python `pleito` livre para uso futuro
