# Checklist jurídico para produto digital brasileiro

Use este checklist na revisão de funcionalidades.

## Empresa e oferta
- [ ] Fornecedor/organizador identificável.
- [ ] Canais de contato definidos.
- [ ] Preço e condições claros.
- [ ] Restrições essenciais visíveis.

## Cadastro
- [ ] Dados coletados têm finalidade definida.
- [ ] Não há coleta desnecessária.
- [ ] Campos obrigatórios são realmente necessários.
- [ ] Fluxo específico para menores, se aplicável.

## Privacidade
- [ ] Política de privacidade.
- [ ] Base legal avaliada por finalidade.
- [ ] Compartilhamentos mapeados.
- [ ] Retenção definida.
- [ ] Direitos do titular operacionalizados.
- [ ] Processo de incidente definido.
- [ ] Terceiros/operadores revisados.

## Aceites
- [ ] Documento tem versão.
- [ ] Data/hora registradas.
- [ ] Usuário/conta identificados.
- [ ] Evidência do aceite preservada.
- [ ] Alterações futuras geram nova versão quando necessário.

## Pagamento
- [ ] Valor total informado.
- [ ] Taxas transparentes.
- [ ] Confirmação da contratação.
- [ ] Política de cancelamento/reembolso.
- [ ] Fluxo de arrependimento avaliado quando aplicável.

## Segurança
- [ ] Autenticação.
- [ ] Autorização.
- [ ] Privilégio mínimo.
- [ ] HTTPS.
- [ ] Senhas protegidas adequadamente.
- [ ] Logs de auditoria.
- [ ] Backup.
- [ ] Gestão de incidentes.
- [ ] Segredos fora do código-fonte.
- [ ] Dependências atualizadas.

## Conteúdo e IP
- [ ] Licenças de imagens/fontes/ícones.
- [ ] Licenças de bibliotecas.
- [ ] Titularidade do código definida.
- [ ] Marca verificada quando relevante.

## Eventos
- [ ] Regulamento.
- [ ] Critérios esportivos.
- [ ] W.O./desempate/penalidades.
- [ ] Premiação.
- [ ] Uso de imagem.
- [ ] Menores.
- [ ] Cancelamento.
- [ ] Alterações de agenda.
